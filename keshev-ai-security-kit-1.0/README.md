# 케셰브 AI 보안 도우미 키트 1.0

과정에서 보안 Agent를 만들며 익힌 방식을 수료 뒤 내 PC를 지키는 데 쓰기 위한 묶음입니다. 내 PC에 이미 로그인해 둔 AI 코딩 도구(Claude Code, Codex CLI, Gemini CLI 가운데 하나)를 **PC 보안 점검과 문제 해결 도우미**로 쓰게 해 줍니다. 과정 앱(케셰브)과는 따로 쓰는 별도 묶음이며, 앱이 켜져 있으면 앱의 「내 PC 상태」 값을 함께 읽을 뿐입니다.

API 키를 새로 발급하거나 이 폴더에 적을 필요가 없습니다. 각 도구에 본인 계정으로 로그인해 둔 상태를 그대로 씁니다. 사용량은 본인 계정의 구독이나 한도에서 차감됩니다. 수료용 도구 안의 ‘개인 AI’ 화면(본인 API 키를 넣는 방식)과는 다른 방법입니다.

## 1. 이 키트가 하는 일과 하지 않는 일

| 하는 일 | 하지 않는 일 |
|---|---|
| 내 PC의 보안 상태를 **읽기만 해서** 모읍니다(백신 실시간 보호, 방화벽, 열린 포트, 시작 프로그램, 디스크, 최근 오류 기록 등). | 설정을 바꾸거나 프로그램을 설치·삭제하지 않습니다. |
| 모은 결과를 AI가 읽고 위험한 곳과 해야 할 일을 우선순위로 정리합니다. | 백신·방화벽·업데이트를 끄라고 권하지 않습니다. |
| 느려짐, 인터넷 끊김, 반복 오류 같은 문제의 원인을 함께 찾습니다. | 내 문서·사진·브라우저 기록·저장된 비밀번호를 열지 않습니다. |
| 원하면 매일 한 번 자동으로 점검하고, 문제가 보일 때만 보고서를 띄웁니다. | 회사 보안 정책이나 IT 담당자의 판단을 대신하지 않습니다. |

고쳐야 할 것이 보이면 AI는 **무엇을, 왜, 어떻게 되돌리는지**까지 설명하고, 실제 변경은 내가 직접 판단해서 실행합니다.

## 2. 준비

1. Windows 10 또는 11 PC
2. 아래 AI 도구 가운데 하나를 설치하고 본인 계정으로 로그인해 둡니다.
   - Claude Code: 터미널에서 `claude`
   - Codex CLI: 터미널에서 `codex`
   - Gemini CLI: 터미널에서 `gemini`
3. 이 ZIP을 **과제 프로젝트 밖의 새 폴더**에 풉니다. 예: `C:\AI보안도우미`. 압축을 풀면 그 안에 `keshev-ai-security-kit-1.0` 폴더가 생깁니다. 아래의 "키트 폴더"는 `README.md` 와 `tools` 폴더가 바로 보이는 이 폴더를 말합니다.

회사 PC라면 먼저 회사 규정에서 AI 도구 사용과 PC 정보 외부 전송이 허용되는지 확인하세요.

## 3. 처음 한 번: 점검 자료 모으기

키트 폴더를 파일 탐색기로 열고, 주소 표시줄에 `powershell` 을 입력해 PowerShell 창을 엽니다. 그리고 아래 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\collect-pc-snapshot.ps1
```

- 1분 안쪽으로 끝나며, `reports` 폴더에 `snapshot-날짜-시각.md` 와 `.json` 이 생깁니다.
- 관리자 권한이 필요 없습니다. 권한이 없어 못 읽은 항목은 "확인 불가"로 남습니다.
- 사용자 폴더·사용자 이름·PC 이름·계정 번호(SID)·IP 주소와 비밀처럼 보이는 값(토큰·비밀번호 인자, 긴 키 문자열)은 `<…>` 로 가려서 저장합니다. 시작 프로그램은 실행 파일 위치만 저장하고 뒤의 인자는 저장하지 않습니다.
- 알려진 형식만 가리므로 완전히 걸러진다고 보장하지는 못합니다. AI에게 보이기 전에 `reports` 의 `.md` 파일을 한 번 열어 확인하세요. 가리기 기능 자체는 `-SelfTest` 를 붙여 실행하면 시험해 볼 수 있습니다.
- 열린 포트·시작 프로그램·오류 기록은 개수 상한이 있습니다. 상한에 걸려 일부만 모은 항목은 「수집 범위」에 따로 표시합니다.
- 과정에서 만든 케셰브 앱이 `http://127.0.0.1:5189` 에서 켜져 있으면, 앱의 「내 PC 상태」 값도 함께 담습니다. 꺼져 있어도 점검은 그대로 진행됩니다.

## 4. AI 도우미와 대화하기

같은 PowerShell 창에서, **키트 폴더 안에서** 쓰는 도구를 실행합니다.

```powershell
claude     # Claude Code
codex      # Codex CLI
gemini     # Gemini CLI
```

키트 폴더에는 `CLAUDE.md`, `AGENTS.md`, `GEMINI.md` 가 들어 있습니다. 각 도구는 실행한 폴더의 이 파일을 자동으로 읽고 "읽기 전용 PC 보안 도우미" 규칙에 따라 움직입니다. 다른 폴더에서 실행하면 이 규칙이 적용되지 않으니 꼭 키트 폴더에서 실행하세요.

대화가 열리면 `prompts` 폴더의 요청문을 하나 골라 붙여 넣습니다.

| 파일 | 언제 쓰나요 |
|---|---|
| `01-전체-보안-점검.md` | 처음 쓸 때, 한 달에 한 번 |
| `02-느려진-PC-원인-찾기.md` | PC가 갑자기 느려졌을 때 |
| `03-인터넷-연결-문제-해결.md` | 인터넷이 끊기거나 특정 사이트만 안 열릴 때 |
| `04-시작-프로그램과-열린-포트-점검.md` | 모르는 프로그램이 켜져 있는 것 같을 때 |
| `05-Windows-오류-기록-해석.md` | 같은 오류 창이 반복될 때 |
| `06-케셰브-앱-화면-해석.md` | 내가 만든 케셰브 앱 화면의 값이 무슨 뜻인지 알고 싶을 때 |
| `07-점검-보고서-쓰기.md` | 점검 결과를 한 장으로 남기고 싶을 때 |

대화형으로 쓸 때는 그 AI 도구에 연결해 둔 다른 기능(메일, GitHub, 파일 편집 등)도 살아 있습니다. 이 키트의 지침이 그런 기능을 쓰지 말라고 막지만, 메일 보내기·파일 삭제·설정 변경 같은 허락 요청이 뜨면 거절하세요.

AI가 명령을 실행하겠다고 물으면 **명령 내용을 읽고** 허락하세요. 읽기만 하는 명령(`Get-…`, `Test-…`)은 허락해도 되고, 무언가를 바꾸는 명령(`Set-…`, `Remove-…`, `Stop-…`, `Disable-…`, 설치·삭제)은 이 키트의 규칙상 AI가 직접 실행하지 않습니다. 그런 명령을 실행하려고 하면 거절하고 설명을 다시 요청하세요.

## 5. (선택) 매일 자동 점검 켜기

매일 정해진 시각에 자료를 모으고 AI가 분석해 `reports\daily-날짜-시각.md` 를 남깁니다. 결과 첫 줄이 "주의"나 "위험"일 때만 메모장으로 보고서를 띄웁니다. 정상인 날에는 조용히 기록만 남깁니다. AI가 실패하거나 첫 줄 형식이 맞지 않으면 정상으로 처리하지 않고 `분석실패` 파일과 기록을 남깁니다. 자동 점검은 Codex CLI와 Claude Code만 지원하며, Gemini CLI는 대화형으로만 쓰세요.

```powershell
# Codex CLI를 쓸 때
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\register-daily-check.ps1 -Agent codex -Time 12:30

# Claude Code를 쓸 때
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\register-daily-check.ps1 -Agent claude -Time 12:30
```

- 내 계정의 작업 스케줄러에 「케셰브 AI 보안 점검」 작업 하나를 등록합니다. 관리자 권한이 필요 없고, 내가 로그인해 있을 때만 실행됩니다.
- 자동 점검은 지침과 방금 모은 점검 요약을 AI에게 글로 넘기고, AI는 그 글만 읽고 보고서를 씁니다. AI에게 키트나 개인 폴더를 작업 공간으로 주지 않고, 비어 있는 `reports\.ai-work` 폴더에서 실행합니다.
  - Claude Code: `claude -p --safe-mode --tools ""` 로 실행해(스크립트 안에서는 Windows PowerShell 5.1 이 빈 인자를 넘기도록 `--tools '""'` 로 적었습니다) 내장 도구를 모두 빼고, 내가 설정한 MCP·훅·플러그인을 끕니다. 회사가 관리 정책으로 넣은 설정은 남을 수 있습니다.
  - Codex CLI: `codex exec --sandbox read-only --ignore-user-config --ignore-rules --ephemeral` 에 `--disable apps`, `--disable shell_tool` 같은 옵션을 더해 실행합니다. 내 설정의 MCP·규칙을 읽지 않고, 계정에 연결한 앱(메일·GitHub 등)·플러그인·셸·브라우저 기능을 기능 플래그로 끄고, 파일과 설정을 바꿀 수 없는 샌드박스에서 돌립니다. 판에 따라 일부 기능이 남을 수 있어서, 지침과 요청문으로도 명령 실행을 금지합니다.
  - 확인한 판은 Claude Code 2.1.285, Codex CLI 0.164.0 입니다. 판이 바뀌어 옵션을 알아듣지 못하면 AI 도구가 오류로 끝나고, 자동 점검은 그 결과를 정상으로 처리하지 않고 `분석실패` 로 남깁니다.
- 매일 실행할 때마다 본인 AI 계정의 사용량이 조금씩 차감됩니다.
- 끄려면 아래 명령을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\unregister-daily-check.ps1
```

등록하지 않고 한 번만 돌려 보려면 `.\tools\daily-check.ps1 -Agent codex` 처럼 직접 실행합니다. `-Agent none` 은 AI 없이 자료만 모읍니다.

## 6. 개인정보와 전송 범위

- 점검 자료는 이 폴더의 `reports` 에만 저장됩니다. AI 도구를 실행하면 AI가 읽은 내용이 해당 AI 회사로 전송됩니다.
- 수집기는 개인 식별 정보와 비밀처럼 보이는 값을 가리지만, 프로그램 이름과 오류 메시지 일부는 그대로 남습니다. 알려진 형식만 가리므로, 보내기 싫은 내용이 있으면 `reports` 의 파일을 먼저 열어 확인하세요.
- 수집기는 비밀번호·API 키·인증서를 일부러 찾아 모으지 않습니다. 그런 값은 AI에게도 알려 주지 마세요.
- 다 쓴 보고서는 언제든 `reports` 폴더에서 지워도 됩니다.

## 7. 과정 앱과의 관계

- 과정에서 만든 케셰브 앱의 사용자·기기·세션·접근 판정 기능은 ALEPH 판정 환경에서 커밋한 코드를 검토하는 방식으로 판정합니다. 코드를 실행하거나 회사 서버에 연결해 본 확인은 아닙니다. 단계마다 '통과'인지, 시스템 문제로 운영 정책에 따라 '임시 통과'로 처리됐는지는 포털 판정 기록에 남아 있습니다.
- 앱의 "서버 연결 안 함"은 외부 서버 연결을 설정하지 않은 기본 실행의 정상 표시입니다. 실제로 연결하려면 접근 제어 서버, 그 서버에 맞는 연결 어댑터, 서버 담당자가 발급하는 개인 인증서가 필요합니다.
- 이 키트는 그 연결 없이도 내 PC 자체를 지키는 데 쓰는 별도 도구입니다. 과제 점수나 공식 통과 기록과는 상관없습니다.

## 8. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| "이 시스템에서 스크립트를 실행할 수 없으므로" | 명령에 `-ExecutionPolicy Bypass` 가 들어 있는지 확인합니다. 이 옵션은 이번 한 번의 실행에만 적용됩니다. |
| `claude`·`codex`·`gemini` 를 찾을 수 없음 | 도구를 설치한 뒤 새 PowerShell 창을 엽니다. 로그인은 각 도구를 처음 실행하면 안내합니다. |
| 백신 항목이 "확인 불가" | 다른 회사 백신을 쓰면 Windows 보안(Defender) 값이 비어 있을 수 있습니다. 쓰는 백신 프로그램 화면에서 실시간 보호를 직접 확인하세요. |
| 자동 점검 보고서가 생기지 않음 | 작업 스케줄러에서 「케셰브 AI 보안 점검」의 마지막 실행 결과를 보고, `reports\daily-check.log` 를 엽니다. `분석실패` 파일이 있으면 AI 도구의 로그인 상태를 확인합니다. |
| 가리기가 제대로 되는지 궁금함 | `.\tools\collect-pc-snapshot.ps1 -SelfTest` 를 실행하면 시험 문자열로 가리기를 확인합니다. PC 정보는 모으지 않습니다. |
