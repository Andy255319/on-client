모르는 프로그램이 켜져 있는 것 같아. reports 폴더의 최신 snapshot에서 시작 프로그램과 열린 포트를 점검해 줘.

- 시작 프로그램마다 이름, 실행 위치, 어떤 프로그램으로 보이는지를 표로 정리해 줘. 확신이 없으면 "확인 필요"로 적어 줘.
- 모든 주소(0.0.0.0, ::)에서 대기하는 포트는 어떤 프로그램인지, 꼭 열려 있어야 하는지 설명해 줘.
- 의심스러운 항목은 내가 확인할 방법(파일 위치 열기, 디지털 서명 확인, 공식 사이트 비교)을 알려 줘.
- 삭제나 차단은 직접 하지 말고, 내가 Windows 설정의 어느 화면에서 끌 수 있는지만 알려 줘.
