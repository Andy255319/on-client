# 케셰브(보안 Agent) 완성본 시연 순서 및 정리 문서

이 문서는 4~6차 방어전 결과물인 **케셰브(보안 Agent)**의 완성본 시연 순서와 기술적 사실을 정리한 공식 문서입니다.  
확인되지 않은 것을 된다고 기술하지 않으며, **실제로 잰 값과 예시 값, 확인 불가의 한계, 실행 근거**를 투명하게 구분하여 기록합니다.

## 3. 핵심 기능 3가지를 보여 주는 1분 시연 순서

### [1단계] 상단 4대 관제 지표 요약 확인
1. `dist\Keshev\케셰브 시작.bat`를 더블클릭하여 앱을 시작합니다. (브라우저 자동 열림)
2. 화면 상단의 **4대 관제 카드**를 확인합니다:
   * **기기 준수 상태**: `[SDP 미연결 · 예제]` 주황색 배지 (확인 불가 / unknown)
   * **로그인 세션**: `[SDP 미연결 · 예제]` 주황색 배지 (`practice-session · 활성 demo`)
   * **내 PC 보안 & 네트워크**: **`[실측]`** 녹색 배지 (방화벽 보호됨 · 로컬 IP 주소)
   * **실시간 위협 및 조치(XDR)**: `[SDP 미연결 · 예제]` 주황색 배지 (위협 1건 탐지 / 조치 대기 0건)
3. **포인트**: 실제 PC에서 측정한 값과 SDP 서버 미연결 모의 데이터가 서로 섞이지 않고 배지로 명확히 구분됨을 설명합니다.

### [2단계] 내 PC 보안·네트워크 구성 실측 현황판 점검
1. 상단 카드 바로 아래의 **「내 PC 보안·네트워크 구성 실측 현황」** 패널을 확인합니다.
2. 다음 실제 측정값들을 확인합니다:
   * **네트워크 구성**: 이더넷 및 가상 어댑터의 실제 IPv4 주소 목록
   * **방화벽 설정 (읽기 전용)**: 도메인, 개인, 공용 프로필 사용 여부 (보호됨)
   * **최근 24시간 Windows 기록**: System 경고·오류 건수 및 Application 경고·오류 건수
   * **필수 안내 문구 확인**:
     > *"안내: 아래 이벤트 기록 건수는 침해나 공격 탐지 결과가 아닙니다. 일반 Windows 시스템 및 응용 프로그램 동작 중 기록된 정상적인 경고·오류입니다."*
3. **포인트**: 관리자 권한을 요구하거나 설정을 변경하지 않고, 안전한 읽기 전용 점검으로 실측했음을 설명합니다.

### [3단계] `[다시 조회]` 버튼 실시간 갱신 및 키보드 조작 시연
1. 현황판 우측 상단의 **`[다시 조회]`** 버튼을 마우스로 클릭하거나, 키보드 `Tab` 키로 포커스를 이동한 후 `Enter` (또는 `Space`)를 누릅니다.
2. 버튼 및 상태 영역에 **`⏳ 로컬 PC 보안 상태 및 Windows 로그 측정 중...`** 대기 문구가 나타나는 것을 확인합니다.
3. 측정이 완료되면 갱신 시각과 메모리 사용량(`heapUsed / heapTotal`), 이벤트 로그 건수가 즉시 최신화되는 것을 확인합니다.
4. **포인트**: 마우스 없이 키보드만으로도 완벽히 조작 가능하며(W3C WAI 준수), 화면 전체 새로고침 없이 비동기로 상태가 복구·갱신됨을 시연합니다.

## 4. 아직 안 되거나 '확인 불가'로 남은 한계 (정직한 기록)

과정의 학습 계약과 원칙에 따라, **구현하지 않았거나 권한상 확인할 수 없는 항목을 정상이나 성공으로 꾸며내지 않고 한계로 정직하게 기록**합니다.

1. **SDP 서버 원천 미연결 (모의 데이터 상태 유지)**:
   * 현재 실제 엔터프라이즈 SDP/ZTNA 서버 및 클라우드 게이트와의 라이브 어댑터는 연결되어 있지 않습니다.
   * 따라서 기기 준수 판정, 사용자 세션, XDR 실시간 위협은 사내 예제 데이터(`[SDP 미연결 · 예제]`)로만 렌더링되며, 실제 외부 침해 차단이나 원천 조치 집행은 지원하지 않습니다.
2. **관리자 권한 요구 보안 설정의 불변경 원칙**:
   * Windows 고급 보안 감사 정책이나 UAC 심층 설정 등 관리자 권한이 필요한 항목은 시스템 무결성을 위해 임의로 변경하거나 공격을 시뮬레이션하지 않았습니다.
   * 권한이 없는 항목은 거짓으로 값을 채우지 않고 **‘확인 불가(unknown)’ 및 접근 권한 필요 안내**로 정직하게 표시합니다.
3. **승인 실행 환경(Provided Runtime) 미설치 상태**:
   * 현재 워크벤치 환경에는 공식 서명된 `APP_PACKAGE_MANIFEST.json`을 발급하는 운영 런타임이 미설치 상태(`PROVIDED_RUNTIME_NOT_INSTALLED`)이며 운영 승인 키가 없습니다.
   * 이를 우회하거나 스크립트를 임의 변조하지 않고, 과정이 인정한 **기본 포장(`dist\Keshev`)**을 채택하여 배포했습니다.

